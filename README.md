# Haze releases

Builds only, no source.

**Download:** [haze_loader.exe](https://github.com/dgcamposs08-afk/haze-releases/releases/latest/download/haze_loader.exe)

Run the loader. It fetches the newest `haze_external.exe` from the latest release, checks its size and SHA-256 against `manifest.json`, installs it to `%LOCALAPPDATA%\Haze` and starts it. Settings, presets and the offsets cache live in that folder and survive updates.
